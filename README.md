# SQlite-pandas
Sales Summary using SQLite & Python

About the Task:
This project shows how to connect Python with a SQLite database to get a basic sales summary using SQL queries and visualize it with a bar chart.


Tools Used:

Python
SQLite
Pandas
Matplotlib


Key Steps:
Connected to sales_data.db using sqlite3
Ran a SQL query to get total quantity and revenue per product
Loaded results into a pandas DataFrame
Displayed output using print() and a simple bar chart
Saved the chart as sales_chart.png


Output:
A table of product-wise quantity and revenue, and a bar chart showing revenue by product.
